# Tunelyst 1.1.48

- Added comfortable all-side launcher padding and aligned brand-mark proportions across the Home drawer, immersive artwork, and splash. The splash remains black and now shows only the icon.
- Added a left-side Home drawer with shortcuts to Settings and Listening Stats.
- Removed the separate Recents playback-history screen while retaining local history for recommendations and Listening Stats.
- Added Material 3 Expressive's circular wavy progress ring around the Home-artwork play/pause button; the center button is white.
- Improved contrast for Settings switches in the off state.
- Colored the expanded Now Playing play/pause control from the current track's local album artwork, with contrast-aware icon tinting.

All listening data remains on-device.
