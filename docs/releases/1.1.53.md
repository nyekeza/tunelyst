# Tunelyst 1.1.53

## Highlights

- Added in-card selection and batch application for reviewed title/artist cleanup suggestions. Selected changes, including proposed filenames, are previewed and confirmed within the cleanup card.
- Added in-card batch selection for likely duplicate tracks. Deletion requires explicit review, keeps at least one unchecked copy in each group, and still requires Android's system approval.
- Removed the explanatory subtitle under the Library cleanup heading and the “YOUR MUSIC” drawer section label.
- Rebalanced every launcher variant. The adaptive color and monochrome foreground layers are scaled to 85% and centered on their original 432×432 canvases; the precomposed density-specific PNG marks are also reduced to 85% while preserving their yellow backgrounds and transparent masks. The adaptive foreground bounds are `(102,125,330,307)`.
- The splash uses the adaptive launcher icon on a black, wordmark-free background; Android/OEM-selected adaptive masking is retained.

## Build and verification

- Version `1.1.53` / code `65`, package `com.tunelyst.music`, minimum SDK 26.
- The last completed unit suite before this icon-only adjustment passed 50 tests across 13 suites. For the 85% rebuild, test sources compiled but Gradle's test workers timed out during startup; no fresh unit-test result is claimed.
- Release compilation and APK packaging succeeded with R8 minification and resource shrinking enabled. The test APK is `Tunelyst-1.1.53-optimized-test.apk` (7,100,043 bytes; SHA-256 `ffddb4cb11b6a647d3fa71efd50c1240f6ef1b85b7827597de166c20b9aa3bf4`).
- The APK's package/version, minimum SDK, signature, alignment, and packaged launcher layers were verified. Both adaptive foreground PNGs inside the APK retain 432×432 dimensions and 85% bounds. In the xxxhdpi raster fallback, the black mark's bounds shrink from 138×102 to 117×87 px while the yellow background and transparent mask are preserved.
- Signed with the local Android debug/test certificate; this is **not** a production-signed release. Signature certificate SHA-256: `4965a3fe099d5686d6d1292aecbbdb9365e7251312dd344f8832e26dc8fa4696`.
- Release lint-vital analysis/report tasks were excluded after the Gradle daemon disappeared under the available memory limit; no lint pass is claimed. Gradle also reported that `libandroidx.graphics.path.so` and `libtaglib.so` could not be stripped, so they are packaged as-is.
- No emulator or physical-device runtime test was performed. Playback and OEM-specific splash behavior are not claimed as runtime-verified.
