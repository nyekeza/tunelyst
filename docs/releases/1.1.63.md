# Tunelyst 1.1.63

Experimental playback-memory test release. After a crossfade, Tunelyst now resets and reuses the inactive Media3 player slot instead of constructing a replacement on the normal path. If resetting the player fails, the service falls back to releasing it and creating a fresh standby player.

Ordinary no-fade track skips are unchanged. This release does not claim the reported memory growth is fixed; please compare repeated skips with fades disabled and enabled, and report whether memory keeps rising or reaches a plateau.
